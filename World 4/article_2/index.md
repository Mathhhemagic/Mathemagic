:::title
Reading Graphs
:::

Graphs of functions show a visual relationship between inputs and outputs. Learning to read key features directly from a graph is an important SAT skill.

:::mini-title
Domain
:::

The **domain** of a function is the set of all possible input values (x-values) for which the function is defined.

:::example
A graph extends from x = −3 to x = 5.  

Domain: −3 ≤ x ≤ 5
:::

:::tip
Domain describes the graph's spread from left to right.
:::

:::mini-title
Range
:::

The **range** of a function is the set of all possible output values (y-values) the function produces.

:::example
A graph's lowest point is at y = −2 and its highest point is at y = 6.  

Range: −2 ≤ y ≤ 6
:::

:::tip
Range describes the graph's spread from bottom to top.
:::

:::mini-title
Intercepts
:::

The **x-intercept** is where the graph crosses the x-axis (y = 0). The **y-intercept** is where the graph crosses the y-axis (x = 0).

:::example
A graph crosses the x-axis at (4, 0) and the y-axis at (0, −3).  

x-intercept: (4, 0)  

y-intercept: (0, −3)
:::

A graph can have more than one x-intercept, but only one y-intercept, since a function can only have one output for each input.

:::mini-title
Increasing and Decreasing
:::

A function is **increasing** where the graph rises from left to right, and **decreasing** where the graph falls from left to right.

:::example
A graph rises from x = −4 to x = 0, then falls from x = 0 to x = 3.  

Increasing: −4 < x < 0  

Decreasing: 0 < x < 3
:::

:::tip
Always read graphs from left to right when describing increasing or decreasing behavior.
:::

:::mini-title
Maximum and Minimum
:::

A **maximum** is the highest point on a graph (or within a given interval). A **minimum** is the lowest point.

:::example
A graph has a peak at (0, 6).  

Maximum: (0, 6)
:::

:::example
A graph has a lowest point at (2, −4).  

Minimum: (2, −4)
:::

A maximum or minimum can be a single high or low point on the entire graph, or just within one section, called a local (or relative) maximum or minimum.

:::tip
The x-coordinate of a max or min tells you where it happens; the y-coordinate tells you the actual max or min value.
:::
