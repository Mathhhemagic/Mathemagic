:::title
Slope
:::

**Slope** describes how steep a line is—how much it rises or falls as it moves from left to right.

:::mini-title
Rise Over Run
:::

Slope is calculated as rise over run:

slope = rise / run

**Rise** is how much a line moves vertically. **Run** is how much a line moves horizontally.

:::example
If a line rises 4 units for every 2 units it runs:  

slope = 4/2 = 2
:::

:::tip
Always read a graph left to right. Run is the horizontal change, rise is the vertical change.
:::

:::mini-title
Slope from a Graph
:::

To find slope from a graph, pick two clear points on the line. Count how many units you move vertically (rise) and how many units you move horizontally (run) to get from one point to the other.

:::example
A line passes through (1, 2) and (4, 8).  

Rise = 8 − 2 = 6  

Run = 4 − 1 = 3  

Slope = 6/3 = 2
:::

:::mini-title
Slope from Points
:::

If you're given two points without a graph, use the slope formula:

slope = (y₂ − y₁) / (x₂ − x₁)

:::example
(3, 5) and (7, 13)  

slope = (13 − 5) / (7 − 3) = 8/4 = 2
:::

:::example
(−2, 6) and (4, −6)  

slope = (−6 − 6) / (4 − (−2)) = −12/6 = −2
:::

:::tip
It doesn't matter which point you call (x₁, y₁) and which you call (x₂, y₂), as long as you stay consistent in both the numerator and denominator.
:::

:::mini-title
Positive vs. Negative Slope
:::

A **positive slope** means the line rises from left to right.

A **negative slope** means the line falls from left to right.

A **zero slope** means the line is horizontal—it doesn't rise or fall.

An **undefined slope** means the line is vertical—there is no run, so the slope formula results in division by zero.

:::example
Line through (1, 2) and (3, 6): slope = (6 − 2)/(3 − 1) = 4/2 = 2 (positive)
:::

:::example
Line through (1, 6) and (3, 2): slope = (2 − 6)/(3 − 1) = −4/2 = −2 (negative)
:::
