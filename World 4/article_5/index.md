:::title
Piecewise & Nonlinear Functions
:::

Not all functions follow a single rule or a straight line. Some functions use different rules for different intervals, and others curve instead of following a constant rate of change.

:::mini-title
Piecewise Functions
:::

A **piecewise function** is a function defined by different rules for different parts of its domain.

:::example
f(x) = x + 2, if x < 0
f(x) = x², if x ≥ 0

To find f(−3), use the first rule since −3 < 0:
f(−3) = −3 + 2 = −1

To find f(2), use the second rule since 2 ≥ 0:
f(2) = 2² = 4
:::

:::tip
Always check which condition the input satisfies before choosing which rule to use.
:::

:::mini-title
Interpreting Nonlinear Graphs
:::

Nonlinear graphs, such as parabolas or curves, don't have a constant rate of change like linear graphs do. Instead, the rate of change varies across the graph.

:::example
A parabola opens upward with a lowest point at (2, −4).
As x moves away from 2 in either direction, the output increases.
:::

:::tip
Unlike linear functions, you can't find a single slope for a nonlinear graph—the steepness changes from point to point.
:::

:::mini-title
Function Behavior
:::

Function behavior describes how a graph acts over different intervals—whether it's increasing, decreasing, or changing direction, and how quickly.

:::example
A curve decreases steeply from x = −4 to x = 0, then decreases slowly from x = 0 to x = 3.
The function is decreasing over the entire interval, but the rate at which it decreases slows down after x = 0.
:::

:::example
A curve increases slowly from x = 0 to x = 2, then increases rapidly from x = 2 to x = 5.
The function is increasing over the entire interval, but the rate of increase speeds up after x = 2.
:::

:::tip
When describing function behavior, note both the direction (increasing/decreasing) and how the rate of change is shifting (speeding up or slowing down).
:::
