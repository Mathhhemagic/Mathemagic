:::title
Function Basics
:::

A **function** is a rule that assigns exactly one output to each input. Functions are often written using function notation, such as f(x).

:::mini-title
Function Notation
:::

f(x) is read as "f of x," and it represents the output of the function f when the input is x.

f(x) does not mean f multiplied by x—it's just notation for a function's output.

:::example
f(x) = 2x + 3
This means the function f takes an input x, multiplies it by 2, and adds 3.
:::

:::tip
The letter used doesn't have to be f—functions can also be written as g(x), h(x), and so on.
:::

:::mini-title
Inputs and Outputs
:::

The **input** is the value you plug into the function. The **output** is the result after applying the function's rule.

:::example
f(x) = x² + 1
Input: x = 3
Output: f(3) = 3² + 1 = 10
:::

Each input corresponds to exactly one output. If a rule assigns a single input to more than one output, it is not a function.

:::mini-title
Evaluating Functions
:::

To evaluate a function, substitute the given value for x, then simplify.

:::example
f(x) = 4x − 5
Find f(2).
f(2) = 4(2) − 5 = 8 − 5 = 3
:::

:::example
g(x) = x² − 3x + 2
Find g(−1).
g(−1) = (−1)² − 3(−1) + 2 = 1 + 3 + 2 = 6
:::

:::tip
Substitute carefully when the input is negative—use parentheses to avoid sign errors.
:::

:::mini-title
Function Rules
:::

A function rule describes how to get from the input to the output. Sometimes you're given a rule and asked to find an input that produces a certain output, working backward.

:::example
f(x) = 3x + 4
If f(x) = 19, find x.
3x + 4 = 19
3x = 15
x = 5
:::

:::example
h(x) = x² − 2
If h(x) = 7, find x.
x² − 2 = 7
x² = 9
x = 3 or x = −3
:::

:::tip
When solving for x instead of f(x), set the function equal to the given output and solve like a regular equation.
:::
