:::title
Comparing Functions
:::

Functions can be represented in different ways—tables, graphs, and equations—but they all describe the same kind of relationship between inputs and outputs. Being able to compare functions across these formats is a key SAT skill.

:::mini-title
Table vs. Graph vs. Equation
:::

The same function can be shown as a table of values, a graph, or an equation. Comparing them means finding the same features (like rate of change or starting value) no matter which format is used.

:::example
Equation: y = 2x + 1

| x | y |  

| 0 | 1 |  

| 1 | 3 |  

| 2 | 5 |

Graph: A line crossing the y-axis at (0, 1), rising 2 units for every 1 unit it moves right.

All three represent the same function.
:::

:::tip
No matter the format, look for the same two features: how fast the output changes, and where it starts.
:::

:::mini-title
Rate of Change
:::

The **rate of change** describes how much the output changes for each unit increase in the input. For a linear function, this is the same as the slope.

:::example
Table:  
| x | y |  

| 1 | 4 |  

| 2 | 7 |  

| 3 | 10 |

Rate of change = (7 − 4)/(2 − 1) = 3
:::

:::example
Graph: A line passes through (0, 5) and (2, 9).  

Rate of change = (9 − 5)/(2 − 0) = 4/2 = 2
:::

:::mini-title
Initial Value
:::

The **initial value** of a function is its output when the input is 0—this is the same as the y-intercept on a graph.

:::example
Table:  

| x | y |  

| 0 | 6 |  

| 1 | 9 |  

| 2 | 12 |

Initial value = 6, since that's the output when x = 0.
:::

:::example
Equation: y = 5x − 2  

Initial value = −2, since that's the value of y when x = 0.
:::

:::tip
If a table doesn't include x = 0, use the rate of change to work backward and find the initial value.
:::

:::mini-title
Comparing Function Features
:::

SAT questions often ask you to compare two functions given in different formats, such as which has a greater rate of change or a higher initial value.

:::example
Function A: y = 3x + 2  

Function B is given by a table:  

| x | y |  

| 0 | 5 |  

| 1 | 8 |  

| 2 | 11 |

Function A's rate of change = 3  

Function B's rate of change = (8 − 5)/(1 − 0) = 3

Function B's initial value = 5  

Function A's initial value = 2

Both functions have the same rate of change, but Function B has a greater initial value.
:::

:::tip
When comparing functions across formats, convert each one to the same feature (rate of change or initial value) before comparing.
:::
