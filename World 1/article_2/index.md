:::title 
Exponents
:::

First, let's define **exponents**.  

Think of exponents as repeated multiplication:
:::example
2⁴ = 2 × 2 × 2 × 2 = 16
:::
The **base** is the number on the bottom, or the 2.

The **exponent** is the number on the top, or the 4.  

:::example  
5² = 5 × 5 = 25
:::
5 is the base, and 2 is the exponent.  

For the SAT, you should be able to quickly identify different exponents, especially **squares** and **cubes**.  

A number **squared** is a number with an exponent of 2.
:::example
4², 6²
:::
A number **cubed** is a number with an exponent of 3.
:::example
2³, 4³
:::
When combining exponents and PEMDAS, it can get quite tricky:
:::example
(2 + 3)² = 5² = 25  

2 + 3² = 2 + 9 = 11
:::
You must first solve inside the parentheses, then use the exponent.  

Remember the rules of multiplying negative and positive numbers? When a **negative** number is raised to an **even** exponent, the result is **positive**.     

When a **negative** number is raised to an **odd** exponent, the result is **negative**.  

:::example
(-2)² = 4
(-2)³ = -8
:::  

Important: Parentheses matter!  

-2² ≠ (-2)²  

-2² keeps the negative outside the exponent, so it equals -4.  

(-2)² = 4 because the negative is included in the base before squaring.

One final note: **Any** number raised to **0** is **1**!

:::example
4⁰ = 1
:::
The rules you learned are just the basics. You will learn more advanced exponent skills in a later unit!
