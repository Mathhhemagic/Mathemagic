:::title
Graphing Lines
:::

The most common way to write a linear equation is **slope-intercept form**:

y = mx + b

Here, m is the slope and b is the y-intercept—the point where the line crosses the y-axis.

:::mini-title
y = mx + b
:::

In this equation, m tells you how steep the line is, and b tells you where the line starts on the y-axis.

:::example
y = 2x + 3
Slope = 2
y-intercept = 3, so the line crosses the y-axis at (0, 3).
:::

:::example
y = −½x − 4
Slope = −½
y-intercept = −4, so the line crosses the y-axis at (0, −4).
:::

:::tip
The y-intercept is always the value of y when x = 0.
:::

:::mini-title
Graphing from an Equation
:::

To graph a line from y = mx + b, start by plotting the y-intercept. Then use the slope to find a second point by moving according to rise over run.

:::example
y = 2x + 1
Start at (0, 1).
Since slope = 2 = 2/1, move up 2 and right 1 to reach (1, 3).
Draw a line through both points.
:::

:::example
y = −¾x + 2
Start at (0, 2).
Since slope = −¾, move down 3 and right 4 to reach (4, −1).
Draw a line through both points.
:::

:::mini-title
Finding Intercepts
:::

The **y-intercept** is where the line crosses the y-axis (x = 0). The **x-intercept** is where the line crosses the x-axis (y = 0).

To find the x-intercept, set y = 0 and solve for x. To find the y-intercept, set x = 0 and solve for y.

:::example
2x + 3y = 12

x-intercept: set y = 0
2x = 12
x = 6, so the x-intercept is (6, 0).

y-intercept: set x = 0
3y = 12
y = 4, so the y-intercept is (0, 4).
:::

:::tip
Setting the other variable to 0 is the fastest way to find either intercept, without needing to rearrange the whole equation.
:::

:::mini-title
Parallel and Perpendicular Lines
:::

**Parallel lines** have the same slope and never intersect.

**Perpendicular lines** intersect at a right angle, and their slopes are negative reciprocals of each other.

:::example
Line 1: y = 3x + 2
Line 2: y = 3x − 5
These lines are parallel, since both have a slope of 3.
:::

:::example
Line 1: y = 2x + 1
Line 2: y = −½x + 4
These lines are perpendicular, since 2 and −½ are negative reciprocals.
:::

:::tip
To find a negative reciprocal, flip the fraction and change the sign.
:::
