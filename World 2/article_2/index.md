:::title
Linear Inequalities
:::

An inequality is a mathematical statement that compares two expressions using <, >, ≤, or ≥ instead of an equal sign. Unlike equations, inequalities often have a range of solutions instead of just one value.

:::mini-title
Solving Inequalities
:::

Solving an inequality works just like solving an equation—isolate the variable using inverse operations.

:::example
x + 4 < 10
x < 6
:::

:::example
3x ≥ 15
x ≥ 5
:::

There is one key difference: when you multiply or divide both sides by a negative number, you must flip the inequality sign.

:::example
−2x < 8
x > −4
:::

:::tip
Always flip the inequality sign when multiplying or dividing both sides by a negative number.
:::

:::mini-title
Compound Inequalities
:::

A **compound inequality** combines two inequalities into one statement, showing that a variable falls between two values.

:::example
−3 < x + 2 < 7
:::

To solve, perform the same operation on all three parts of the inequality.

:::example
−3 < x + 2 < 7
−3 − 2 < x < 7 − 2
−5 < x < 5
:::

This means x can be any value between −5 and 5.

:::mini-title
Graphing Inequalities
:::

Inequalities can be graphed on a number line.

Use an open circle for < or > (the endpoint is not included), and a closed circle for ≤ or ≥ (the endpoint is included).

:::example
x > 3
:::

Draw an open circle at 3, with an arrow extending to the right.

:::example
x ≤ −1
:::

Draw a closed circle at −1, with an arrow extending to the left.

For a compound inequality like −5 < x < 5, draw open circles at both −5 and 5, with a line connecting them.

:::mini-title
SAT Inequality Wording
:::

The SAT often describes inequalities using words instead of symbols. Recognizing these phrases is key to setting up the correct inequality.

**"At least"** means greater than or equal to (≥).

**"At most"** means less than or equal to (≤).

**"No more than"** means less than or equal to (≤).

**"Exceeds"** or **"more than"** means strictly greater than (>).

**"Fewer than"** or **"less than"** means strictly less than (<).

:::example
A parking garage charges no more than $20 per day.
This means: cost ≤ 20
:::

:::tip
Words like "at least" and "at most" include the boundary value, while "more than" and "less than" do not.
:::
