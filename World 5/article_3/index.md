:::title

Quadratic Applications

:::

Quadratic equations can be used to model many real-world situations. On the SAT, you may see quadratics used to describe height, area, profit, or other quantities.

:::mini-title

Projectile Motion

:::

When an object is thrown or launched, its height can often be modeled by a quadratic function.

A negative x² coefficient means the parabola opens downward, which represents an object rising and then falling.

:::example

h(t) = −16t² + 64t + 5

:::

Here, h(t) represents the height of the object and t represents time.

To find when the object reaches the ground, set the height equal to zero and solve.

:::example

−16t² + 64t + 5 = 0

:::

The solutions represent the times when the object's height is zero. In a real-world problem, a negative time would not make sense, so only the positive solution would be used.

:::mini-title

Maximum and Minimum

:::

The vertex of a parabola represents its maximum or minimum value.

If the parabola opens downward, the vertex gives the **maximum** value. If the parabola opens upward, the vertex gives the **minimum** value.

:::example

h(t) = −2t² + 12t + 3

:::

Since the coefficient of t² is negative, the parabola opens downward. The vertex therefore represents the maximum height.

The time of the maximum can be found using the axis of symmetry:

t = −b⁄2a

:::example

t = −12⁄2(−2)

t = 3

:::

Substitute t = 3 into the function to find the maximum height.

:::example

h(3) = −2(3)² + 12(3) + 3

h(3) = −18 + 36 + 3

h(3) = 21

:::

The maximum height is 21 units.

:::tip

For a quadratic in standard form, the vertex occurs at x = −b⁄2a. If the parabola opens downward, this gives the maximum value. If it opens upward, it gives the minimum value.

:::

:::mini-title

Quadratic Word Problems

:::

Quadratic equations can model real-world relationships involving area, height, profit, and other quantities.

Start by identifying what the variables represent. Then use the information in the problem to write or interpret the quadratic equation.

:::example

A rectangular garden has a length that is 3 feet greater than its width. Its area is 40 square feet. What is the width of the garden?

:::

Let the width be x.

The length is x + 3.

Use the area formula:

x(x + 3) = 40

x² + 3x = 40

x² + 3x − 40 = 0

(x + 8)(x − 5) = 0

x = −8 or x = 5

A length cannot be negative, so the width is 5 feet.

:::tip

In word problems, check whether every solution makes sense in the real-world situation. A negative length, time, or number of objects usually cannot be used.

:::

:::mini-title

Using the Vertex in Applications

:::

Some word problems ask for the greatest or least possible value. These questions often involve the vertex of a quadratic.

:::example

A company's profit is modeled by

P(x) = −x² + 20x − 75

where x is the number of products sold in hundreds.

How many products should the company sell to maximize its profit?

:::

The parabola opens downward because the coefficient of x² is negative.

Find the x-coordinate of the vertex:

x = −20⁄2(−1)

x = 10

Since x represents hundreds of products, the company should sell 1,000 products to maximize its profit.
