:::title

Factoring Basics

:::

Factoring is the process of rewriting an expression as a product of simpler expressions.

Factoring is the opposite of **distributing**. Instead of multiplying expressions together, we find the factors that were multiplied.

:::example

6x + 12

6(x + 2)

:::

The expression 6x + 12 has been factored into 6(x + 2).

:::mini-title

Greatest Common Factor

:::

The **greatest common factor (GCF)** is the largest factor that divides every term of an expression.

To factor out the GCF, find the GCF of all the terms and divide each term by it.

:::example

12x + 18

GCF = 6

6(2x + 3)

:::

Always check that multiplying the GCF back into the parentheses gives the original expression.

:::example

8x² + 12x

GCF = 4x

4x(2x + 3)

:::

:::mini-title

Factoring Trinomials

:::

A **trinomial** is a polynomial with three terms. Some trinomials can be factored into two binomials.

For a trinomial in the form x² + bx + c, find two numbers that multiply to c and add to b.

:::example

x² + 7x + 12

3 × 4 = 12

3 + 4 = 7

(x + 3)(x + 4)

:::

The signs of the numbers matter. If the constant is positive, the two numbers have the same sign. If the constant is negative, the two numbers have opposite signs.

:::example

x² − 5x + 6

−2 × −3 = 6

−2 + −3 = −5

(x − 2)(x − 3)

:::

:::tip

After factoring, multiply the factors back together to check your answer.

:::

:::mini-title

Difference of Squares

:::

A **difference of squares** is an expression in the form a² − b².

A difference of squares can be factored using the pattern:

a² − b² = (a − b)(a + b)

:::example

x² − 25

x² − 5²

(x − 5)(x + 5)

:::

:::example

4x² − 9

(2x)² − 3²

(2x − 3)(2x + 3)

:::

Remember that the expression must be a **difference** of two squares. A sum of squares, such as x² + 25, does not factor using this pattern.

:::tip

When you see two perfect squares separated by subtraction, check for the difference of squares pattern.

:::
:::title

Solving Quadratics

:::

A **quadratic equation** is an equation that can be written in the form ax² + bx + c = 0, where a ≠ 0.

Quadratic equations can be solved in several ways. On the SAT, the most useful methods are factoring, using square roots, completing the square, and the quadratic formula.

:::mini-title

Solving by Factoring

:::

If a quadratic can be factored, set each factor equal to zero and solve.

:::example

x² + 5x + 6 = 0

(x + 2)(x + 3) = 0

x + 2 = 0

x = −2

x + 3 = 0

x = −3

:::

This works because if two factors multiply to zero, at least one of the factors must equal zero.

:::example

x² − 9x + 20 = 0

(x − 4)(x − 5) = 0

x − 4 = 0

x = 4

x − 5 = 0

x = 5

:::

:::tip

When solving by factoring, make sure the equation is equal to zero before setting the factors equal to zero.

:::

:::mini-title

Solving Using Square Roots

:::

Some quadratic equations can be solved by isolating x² and then taking the square root of both sides.

Remember that taking the square root of both sides gives both a positive and negative solution.

:::example

x² = 25

x = ±5

x = 5 or x = −5

:::

:::example

(x − 3)² = 16

x − 3 = ±4

x = 3 ± 4

x = 7 or x = −1

:::

:::tip

Do not forget the ± when taking the square root of both sides.

:::

:::mini-title

Completing the Square

:::

**Completing the square** rewrites a quadratic expression as a perfect square.

To complete the square for x² + bx, add (b ÷ 2)² to both sides.

:::example

x² + 6x = 7

x² + 6x + 9 = 7 + 9

(x + 3)² = 16

x + 3 = ±4

x = 1 or x = −7

:::

The goal is to create a perfect square trinomial that can be solved using square roots.

:::example

x² − 8x = 9

x² − 8x + 16 = 9 + 16

(x − 4)² = 25

x − 4 = ±5

x = 9 or x = −1

:::

:::mini-title

The Quadratic Formula

:::

When a quadratic is difficult to factor or solve by completing the square, the **quadratic formula** can be used.

For an equation in the form ax² + bx + c = 0, the quadratic formula is:

x = (−b ± √(b² − 4ac))⁄2a

:::example

x² + 2x − 8 = 0

a = 1

b = 2

c = −8

x = (−2 ± √(2² − 4(1)(−8)))⁄2(1)

x = (−2 ± √36)⁄2

x = (−2 ± 6)⁄2

x = 2 or x = −4

:::

The expression b² − 4ac is called the **discriminant**. It can help determine how many real solutions a quadratic has.

:::example

x² − 6x + 9 = 0

a = 1

b = −6

c = 9

b² − 4ac = (−6)² − 4(1)(9)

= 36 − 36

= 0

:::

A discriminant of 0 means the quadratic has exactly one real solution.

:::tip

Before using the quadratic formula, identify a, b, and c carefully. Remember that b and c include their signs.

:::

:::mini-title

Choosing a Method

:::

Factoring is usually the quickest method when the quadratic factors easily.

Use square roots when the equation can be written with a squared expression equal to a constant.

Completing the square is useful when you can easily create a perfect square.

The quadratic formula works for any quadratic equation and is especially useful when factoring is difficult.

:::example

2x² + 7x + 3 = 0

(2x + 1)(x + 3) = 0

2x + 1 = 0

x = −1⁄2

x + 3 = 0

x = −3

:::
