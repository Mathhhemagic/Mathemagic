:::title

Graphing Parabolas

:::

A **parabola** is the graph of a quadratic function. A quadratic function can be written in the form y = ax² + bx + c.

The value of a affects the shape and direction of the parabola.

:::example

y = x²

y = 2x²

y = −x²

:::

When a is positive, the parabola opens upward. When a is negative, the parabola opens downward.

:::mini-title

Vertex

:::

The **vertex** is the highest or lowest point of a parabola.

If the parabola opens upward, the vertex is the minimum point. If it opens downward, the vertex is the maximum point.

A quadratic written in vertex form makes the vertex easy to identify:

y = a(x − h)² + k

The vertex is (h, k).

:::example

y = (x − 3)² + 2

Vertex: (3, 2)

:::

Be careful with the sign inside the parentheses. If the equation contains x + 4, the x-coordinate of the vertex is −4.

:::example

y = (x + 4)² − 1

Vertex: (−4, −1)

:::

:::mini-title

Axis of Symmetry

:::

The **axis of symmetry** is the vertical line that divides a parabola into two matching halves.

The axis of symmetry always passes through the vertex.

If the vertex is (h, k), the axis of symmetry is:

x = h

:::example

y = (x − 5)² + 3

Vertex: (5, 3)

Axis of symmetry: x = 5

:::

For a quadratic in standard form, y = ax² + bx + c, the axis of symmetry is:

x = −b⁄2a

:::example

y = x² − 6x + 5

x = −(−6)⁄2(1)

x = 6⁄2

x = 3

:::

The axis of symmetry is x = 3.

:::mini-title

Opening Direction

:::

The sign of a determines which direction the parabola opens.

If a > 0, the parabola opens upward.

If a < 0, the parabola opens downward.

:::example

y = 2x² + 4

The value of a is 2, which is positive.

The parabola opens upward.

:::

:::example

y = −3x² + 2

The value of a is −3, which is negative.

The parabola opens downward.

:::

:::tip

Look at the coefficient of x² first. A positive coefficient means the parabola opens up, and a negative coefficient means it opens down.

:::

:::mini-title

Zeros and x-Intercepts

:::

The **zeros** of a quadratic are the x-values that make the function equal to zero.

On a graph, the zeros are the **x-intercepts**, where the parabola crosses or touches the x-axis.

To find the zeros algebraically, set y equal to zero and solve the resulting quadratic equation.

:::example

y = x² − 5x + 6

0 = x² − 5x + 6

0 = (x − 2)(x − 3)

x = 2 or x = 3

The x-intercepts are (2, 0) and (3, 0).

:::

A parabola can have two x-intercepts, one x-intercept, or no x-intercepts.

:::example

y = (x − 4)²

0 = (x − 4)²

x = 4

The parabola has one x-intercept: (4, 0).

:::

If the parabola never reaches the x-axis, it has no real zeros and no x-intercepts.

:::tip

Zeros are x-values, while x-intercepts are points. If a zero is x = 3, the corresponding x-intercept is (3, 0).

:::

:::mini-title

Putting It All Together

:::

The vertex, axis of symmetry, opening direction, and x-intercepts give important information about the shape and location of a parabola.

:::example

y = x² − 4x + 3

Factor to find the zeros:

0 = x² − 4x + 3

0 = (x − 1)(x − 3)

x = 1 or x = 3

The x-intercepts are (1, 0) and (3, 0).

Find the axis of symmetry:

x = −(−4)⁄2(1)

x = 2

Substitute x = 2 to find the vertex:

y = (2)² − 4(2) + 3

y = 4 − 8 + 3

y = −1

The vertex is (2, −1).

Since a = 1 is positive, the parabola opens upward.

:::

The axis of symmetry passes through the midpoint of the two x-intercepts. For this parabola, the x-intercepts are 1 and 3, so their midpoint is 2.
