:::title
Systems Basics
:::

A **system of equations** is a set of two or more equations with the same variables. Solving a system means finding the values that make all equations true at the same time.

:::mini-title
Substitution
:::

**Substitution** works by solving one equation for a variable, then plugging that expression into the other equation.

:::example
y = x + 3
2x + y = 12

Substitute y = x + 3 into the second equation:
2x + (x + 3) = 12
3x + 3 = 12
3x = 9
x = 3

Then find y:
y = 3 + 3 = 6

Solution: (3, 6)
:::

:::tip
Substitution works best when one equation is already solved for a variable, or can easily be.
:::

:::mini-title
Elimination
:::

**Elimination** works by adding or subtracting the two equations to cancel out one variable.

:::example
x + y = 10
x − y = 4

Add the equations:
2x = 14
x = 7

Then find y:
7 + y = 10
y = 3

Solution: (7, 3)
:::

Sometimes you need to multiply one or both equations first, so the coefficients of a variable match.

:::example
2x + 3y = 16
x + y = 7

Multiply the second equation by 2:
2x + 2y = 14

Subtract from the first equation:
(2x + 3y) − (2x + 2y) = 16 − 14
y = 2

Then find x:
x + 2 = 7
x = 5

Solution: (5, 2)
:::

:::tip
Choose the variable that's easiest to cancel out—look for coefficients that are the same or easy to match.
:::

:::mini-title
Graphing Systems
:::

A system of equations can also be solved by graphing both lines. The solution is the point where the lines intersect.

:::example
y = x + 1
y = −x + 5

Both lines can be graphed using slope-intercept form. They intersect at (2, 3), which is the solution to the system.
:::

If the lines are parallel, the system has no solution. If the lines are the same line, the system has infinitely many solutions.

:::tip
Graphing is useful for understanding what a solution represents, but substitution and elimination are usually faster and more accurate on the SAT.
:::
