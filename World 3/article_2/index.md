:::title
Special Systems
:::

Not every system of equations has exactly one solution. Depending on how the two lines relate to each other, a system can have no solution, one solution, or infinitely many solutions.

:::mini-title
No Solution
:::

A system has **no solution** when the two lines are parallel; they have the same slope but different y-intercepts. Since parallel lines never intersect, there is no point that satisfies both equations.

:::example
y = 2x + 3  

y = 2x − 1

Both lines have a slope of 2, but different y-intercepts, so they never meet.
:::

If you try to solve this system algebraically, the variables cancel out and leave a false statement.

:::example
y = 2x + 3  

y = 2x − 1

Set the equations equal:
2x + 3 = 2x − 1  

3 = −1

This is false, so the system has no solution.
:::

:::tip
If solving a system leads to a false statement (like 3 = −1), the system has no solution.
:::

:::mini-title
Infinite Solutions
:::

A system has **infinitely many solutions** when both equations represent the same line. Every point on the line satisfies both equations.

:::example
y = 3x + 2  

2y = 6x + 4

Divide the second equation by 2:
y = 3x + 2

Both equations are identical, so every point on the line is a solution.
:::

If you solve this system algebraically, the variables cancel out and leave a true statement.

:::example
y = 3x + 2  

2y = 6x + 4

Set the equations equal (after dividing the second by 2):
3x + 2 = 3x + 2  

2 = 2

This is always true, so the system has infinitely many solutions.
:::

:::tip
If solving a system leads to a true statement (like 2 = 2), the system has infinitely many solutions.
:::

:::mini-title
Dependent Systems
:::

A system with infinitely many solutions is also called a **dependent system**, since one equation is just a multiple of the other. 

:::example
x + y = 5  

2x + 2y = 10

The second equation is exactly the first equation multiplied by 2, so both describe the same line.
:::

:::tip
On the SAT, if you're asked for a missing coefficient that makes a system have no solution or infinite solutions, set up the ratios of the coefficients and compare them to the constant terms.
:::
