:::title

Statistics

:::

**Statistics** is the study of collecting, organizing, and interpreting data.

A data set is a collection of values. Statistics can help describe the center and spread of a data set.

:::mini-title

Mean

:::

The **mean** is the average of a data set. To find the mean, add all the values and divide by the number of values.


::contentReference[oaicite:0]{index=0}


:::example

Find the mean of 4, 6, 8, 10, and 12.

Mean = (4 + 6 + 8 + 10 + 12)⁄5

Mean = 40⁄5

Mean = 8

:::

A data set with a larger value can have its mean pulled toward that value.

:::example

The mean of 5, 6, 7, and 8 is:

(5 + 6 + 7 + 8)⁄4 = 6.5

If 20 is added to the data set:

(5 + 6 + 7 + 8 + 20)⁄5 = 9.2

:::

:::mini-title

Median

:::

The **median** is the middle value of a data set when the values are arranged in order.

:::example

Find the median of 3, 7, 8, 10, and 14.

3, 7, 8, 10, 14

The median is 8.

:::

If there is an even number of values, the median is the mean of the two middle values.

:::example

Find the median of 2, 5, 7, 9, 12, and 15.

The two middle values are 7 and 9.

Median = (7 + 9)⁄2

Median = 8

:::

:::tip

Always arrange the data from least to greatest before finding the median.

:::

:::mini-title

Range

:::

The **range** describes the difference between the greatest and least values in a data set.

Range = greatest value − least value

:::example

Find the range of 4, 9, 12, 15, and 21.

Range = 21 − 4

Range = 17

:::

A larger range means the data values span a wider interval.

:::example

Data set A: 5, 6, 7, 8, 9

Data set B: 2, 4, 7, 10, 12

:::

Both data sets have a median of 7, but data set B has a greater range.

:::mini-title

Standard Deviation

:::

**Standard deviation** describes how spread out the values in a data set are from the mean.

A small standard deviation means the values are clustered close to the mean. A large standard deviation means the values are more spread out.




:::example

Data set A: 4, 5, 5, 6, 5

Data set B: 1, 3, 7, 9, 5

:::

Both data sets have a mean of 5, but the values in data set A are closer to the mean. Therefore, data set A has the smaller standard deviation.

The SAT may ask you to compare standard deviations without requiring you to calculate them directly.

:::tip

A larger standard deviation means more spread. A smaller standard deviation means less spread.

:::
