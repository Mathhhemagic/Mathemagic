:::title

Exponential Growth

:::

An **exponential function** is a function in which the variable appears in the exponent.

A common form of an exponential function is:

y = a(b)ˣ

The value of a represents the starting amount, and b represents the growth or decay factor.

:::example

y = 100(1.05)ˣ

:::

The starting amount is 100, and the growth factor is 1.05.

:::mini-title

Growth Models

:::

An exponential growth model is used when a quantity increases by the same percentage over equal intervals of time.

For growth, the growth factor is greater than 1.

:::example

A population starts at 500 and grows by 10% each year.

y = 500(1.10)ˣ

:::

The 1.10 comes from adding the 10% growth to the original 100%:

100% + 10% = 110% = 1.10

:::example

A car is worth $20,000 and increases in value by 4% each year.

y = 20,000(1.04)ˣ

:::

The exponent represents the number of growth periods.

:::tip

For a growth rate of r, the growth factor is 1 + r. Make sure the percentage is written as a decimal before adding it to 1.

:::

:::mini-title

Decay Models

:::

An exponential decay model is used when a quantity decreases by the same percentage over equal intervals of time.

For decay, the decay factor is between 0 and 1.

:::example

A machine is worth $8,000 and loses 15% of its value each year.

y = 8,000(0.85)ˣ

:::

The 0.85 comes from subtracting the 15% decrease from the original 100%:

100% − 15% = 85% = 0.85

:::example

A population of 2,000 decreases by 6% each year.

y = 2,000(0.94)ˣ

:::

:::tip

For a decay rate of r, the decay factor is 1 − r.

:::

:::mini-title

Exponential Graphs

:::

The graph of an exponential function has a characteristic curved shape.

For y = a(b)ˣ, the value of b determines whether the function shows growth or decay.

If b > 1, the function shows exponential growth.

If 0 < b < 1, the function shows exponential decay.

:::example

y = 2(3)ˣ

:::

Since the base is 3, which is greater than 1, the graph shows exponential growth.

:::example

y = 5(0.5)ˣ

:::

Since the base is 0.5, which is between 0 and 1, the graph shows exponential decay.

The graph of y = a(b)ˣ has a y-intercept of (0, a), because any nonzero number raised to the zero power is 1.

:::example

y = 4(2)ˣ

When x = 0:

y = 4(2)⁰

y = 4

The y-intercept is (0, 4).

:::

:::tip

For y = a(b)ˣ, the starting value a is the y-intercept. The base b tells you whether the function grows or decays.

:::
