:::title

Polynomials

:::

A **polynomial** is an expression made up of terms that contain constants, variables, and nonnegative whole-number exponents.

Polynomials can be added, subtracted, multiplied, and factored using many of the same skills you've already learned.

:::example

3x² + 2x − 5

:::

This polynomial has three terms. The highest exponent is 2, so it is a quadratic polynomial.

:::mini-title

Adding Polynomials

:::

To add polynomials, combine **like terms**. Like terms have the same variable raised to the same power.

:::example

(3x² + 4x + 2) + (2x² + 5x − 7)

3x² + 2x² + 4x + 5x + 2 − 7

5x² + 9x − 5

:::

When adding polynomials, the signs of the terms stay the same.

:::example

(4x² − 3x + 6) + (x² + 7x − 2)

5x² + 4x + 4

:::

:::mini-title

Subtracting Polynomials

:::

To subtract polynomials, distribute the negative sign to every term in the polynomial being subtracted. Then combine like terms.

:::example

(5x² + 3x − 4) − (2x² + x − 6)

5x² + 3x − 4 − 2x² − x + 6

3x² + 2x + 2

:::

A common mistake is forgetting to change the sign of every term inside the parentheses.

:::tip

When subtracting a polynomial, distribute the negative sign before combining like terms.

:::

:::mini-title

Multiplying Polynomials

:::

To multiply polynomials, use the **distributive property** to multiply every term in one polynomial by every term in the other.

:::example

3x(x + 4)

3x² + 12x

:::

When multiplying powers with the same base, add the exponents.

:::example

x²(x + 5)

x³ + 5x²

:::

For two binomials, multiply each term in the first binomial by each term in the second.

:::example

(x + 3)(x + 5)

x² + 5x + 3x + 15

x² + 8x + 15

:::

:::tip

Make sure every term is multiplied by every term in the other polynomial.

:::

:::mini-title

Polynomial Factoring

:::

Factoring a polynomial means rewriting it as a product of simpler expressions.

Start by looking for a **greatest common factor (GCF)**. If every term has a common factor, factor it out first.

:::example

6x² + 9x

3x(2x + 3)

:::

Some quadratic polynomials can then be factored into two binomials.

:::example

x² + 7x + 12

(x + 3)(x + 4)

:::

The two numbers must multiply to the constant term and add to the coefficient of x.

:::example

x² − 5x + 6

(x − 2)(x − 3)

:::

Remember that factoring reverses multiplication. You can check a factorization by multiplying the factors back together.

:::example

(x + 2)(x + 5)

x² + 5x + 2x + 10

x² + 7x + 10

:::

:::tip

When factoring, always check for a GCF before looking for other factoring patterns.

:::
