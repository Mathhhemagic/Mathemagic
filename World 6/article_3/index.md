:::title

Radicals

:::

A **radical** is an expression that represents a root. The most common radical is the square root.

:::example

√25 = 5

√49 = 7

:::

A square root asks which number, when multiplied by itself, gives the number inside the radical.

:::mini-title

Simplifying Radicals

:::

To simplify a radical, look for perfect square factors inside the radical.

:::example

√12

= √(4 × 3)

= √4 × √3

= 2√3

:::

If the number inside the radical has no perfect square factors other than 1, the radical is already simplified.

:::example

√7

:::

When variables are inside a square root, look for factors that are perfect squares.

:::example

√(18x²)

= √(9 × 2 × x²)

= 3x√2

:::

:::tip

Look for the largest perfect square factor when simplifying a square root.

:::

:::mini-title

Adding and Subtracting Radicals

:::

Radicals can be added or subtracted when they have the same radical part.

:::example

3√5 + 2√5

= 5√5

:::

If the radical parts are different, combine them only after simplifying each radical.

:::example

√12 + √27

= 2√3 + 3√3

= 5√3

:::

:::mini-title

Radical Equations

:::

To solve a radical equation, isolate the radical first. Then raise both sides to the appropriate power.

:::example

√x = 6

x = 36

:::

For equations involving a square root, squaring both sides can remove the radical.

:::example

√(x + 4) = 7

x + 4 = 49

x = 45

:::

When an equation has more than one radical or more complicated expressions, you may need to square both sides more than once.

:::example

√(x + 1) = x − 1

x + 1 = (x − 1)²

x + 1 = x² − 2x + 1

x² − 3x = 0

x(x − 3) = 0

x = 0 or x = 3

:::

Not every solution found after squaring will work in the original equation. Check your answers in the original equation.

:::tip

Always check solutions to radical equations in the original equation. Squaring both sides can sometimes create an extraneous solution.

:::

:::mini-title

Rational Exponents

:::

A **rational exponent** is an exponent written as a fraction. Rational exponents can be rewritten as radicals.

An exponent of 1⁄n represents the nth root.

:::example

x¹⁄² = √x

x¹⁄³ = ∛x

:::

If the numerator is greater than 1, the numerator represents a power and the denominator represents the root.

:::example

x²⁄³

= (∛x)²

:::

:::example

16³⁄⁴

= (⁴√16)³

= 2³

= 8

:::

Rational exponents and radicals are two different ways of writing the same expression.

:::example

27²⁄³

= (∛27)²

= 3²

= 9

:::

:::tip

For a rational exponent, the denominator tells you the root and the numerator tells you the power.

:::
