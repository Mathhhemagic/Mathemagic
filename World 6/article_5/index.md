:::title

Rational Expressions

:::

A **rational expression** is a fraction in which the numerator and denominator are polynomials.

:::example

(x + 3)⁄(x − 2)

:::

Rational expressions can be simplified by factoring the numerator and denominator and then canceling common factors.

:::mini-title

Simplifying Rational Expressions

:::

To simplify a rational expression, first factor the numerator and denominator. Then cancel any common factors.

:::example

(x² + 5x + 6)⁄(x + 2)

= ((x + 2)(x + 3))⁄(x + 2)

= x + 3

:::

Only factors can be canceled. Terms that are being added or subtracted cannot be canceled separately.

:::example

(x + 3)⁄x

:::

The x cannot be canceled because x and 3 are terms, not factors.

:::tip

Factor before canceling. You can only cancel factors that are multiplied together.

:::

:::mini-title

Restrictions

:::

A rational expression cannot have a denominator of zero.

To find the **restrictions**, set the original denominator equal to zero and solve.

:::example

1⁄(x − 4)

x − 4 = 0

x = 4

:::

The restriction is x ≠ 4.

Even if a factor is canceled when simplifying, the original restriction still applies.

:::example

(x² − 16)⁄(x − 4)

= ((x − 4)(x + 4))⁄(x − 4)

= x + 4

:::

The simplified expression is x + 4, but x = 4 is still a restriction because the original expression had a denominator of zero.

:::tip

Always find restrictions from the original denominator, not the simplified expression.

:::

:::mini-title

Rational Equations

:::

A **rational equation** is an equation that contains one or more rational expressions.

To solve a rational equation, first identify the restrictions. Then multiply both sides by a common denominator to eliminate the fractions.

:::example

1⁄x = 3

Multiply both sides by x:

1 = 3x

x = 1⁄3

:::

The solution x = 1⁄3 does not violate the restriction x ≠ 0, so it is valid.

:::example

2⁄x + 1 = 5

2⁄x = 4

2 = 4x

x = 1⁄2

:::

For more complicated rational equations, multiply every term by the least common denominator.

:::example

1⁄x + 1⁄2 = 3⁄4

Multiply every term by 4x:

4 + 2x = 3x

x = 4

:::

Always check that your solution does not make any original denominator equal to zero.

:::tip

Before solving a rational equation, find the restrictions. After solving, check that your answer is allowed.
:::
