:::title
Exponents
:::

An **exponent** tells you how many times to multiply a base by itself.

:::example
2⁴ = 2 × 2 × 2 × 2 = 16
:::

:::mini-title
Exponent Rules
:::

When multiplying powers with the same base, add the exponents.

:::example
x³ × x⁴ = x³⁺⁴ = x⁷
:::

When dividing powers with the same base, subtract the exponents.

:::example
x⁶ ÷ x² = x⁶⁻² = x⁴
:::

When raising a power to another power, multiply the exponents.

:::example
(x³)² = x³ˣ² = x⁶
:::

When a product is raised to a power, apply the exponent to each factor.

:::example
(2x)³ = 2³x³ = 8x³
:::

Any nonzero number raised to the power of 0 equals 1.

:::example
5⁰ = 1
:::

:::tip
These rules only apply when the bases are the same. You can't combine exponents like x³ × y⁴.
:::

:::mini-title
Negative Exponents
:::

A negative exponent means take the reciprocal of the base raised to the positive version of that exponent.

x⁻ⁿ = 1/xⁿ

:::example
2⁻³ = 1/2³ = ⅛
:::

:::example
x⁻² = 1/x²
:::

This also works in reverse—a negative exponent in the denominator moves to the numerator.

:::example
1/x⁻⁴ = x⁴
:::

:::tip
A negative exponent does not make the value negative—it means "reciprocal," not "opposite."
:::

:::mini-title
Fractional Exponents
:::

A fractional exponent represents a root. The denominator of the fraction is the root, and the numerator is the power.

x^(1/n) = ⁿ√x

x^(m/n) = ⁿ√(xᵐ)

:::example
x^(1/2) = √x
:::

:::example
8^(1/3) = ³√8 = 2
:::

:::example
4^(3/2) = (√4)³ = 2³ = 8
:::

:::tip
It's usually easier to take the root first, then raise to the power, to keep the numbers small.
:::

:::mini-title
Scientific Notation
:::

**Scientific notation** writes very large or very small numbers as a number between 1 and 10 multiplied by a power of 10.

:::example
450,000 = 4.5 × 10⁵
:::

:::example
0.00032 = 3.2 × 10⁻⁴
:::

To convert from scientific notation back to standard form, move the decimal point based on the exponent—right for a positive exponent, left for a negative exponent.

:::example
6.1 × 10³ = 6,100
:::

:::tip
When multiplying numbers in scientific notation, multiply the front numbers and add the exponents.
:::
